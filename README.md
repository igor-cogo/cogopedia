# Cogopedia

Línguas e nomes de lugares do Brasil — https://igor-cogo.github.io/cogopedia/

- `docs/` — páginas do site (Markdown)
- `tools/converter.py` — converte os verbetes DOCX em páginas: `python3 tools/converter.py <pasta_docx> <pasta_destino>`
- `mkdocs.yml` — configuração e menu do site

Cada envio para a branch `main` publica o site automaticamente (GitHub Actions).
